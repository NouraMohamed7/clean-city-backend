# Clean City Backend

Laravel API backend for Clean City project.

## Features
- Authentication system
- Reports management
- Categories & Cities
- Companies dashboard
- Admin panel APIs
- Leaderboard system

## Tech Stack
- Laravel
- MySQL
- Sanctum Authentication

## Setup
1. composer install
2. cp .env.example .env
3. php artisan key:generate
4. php artisan migrate --seed
5. php artisan serve
